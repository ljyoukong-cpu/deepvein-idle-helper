# Deep Vein Idle 自给成长与职业助手

[安装或更新脚本](https://raw.githubusercontent.com/ljyoukong-cpu/deepvein-idle-helper/main/deepvein-balanced.user.js)

用于 [Deep Vein Idle](https://deepveinidle.com/) 的 Tampermonkey 用户脚本。按阶段补齐生活技能与所选职业，兼顾供料、金币、装备和后台农业；默认暂停，首次安装后刷新游戏，选择职业并点击“开始”。

- 自采、自制与按需采购结合；按实时卖盘、筹币时间、往返及放弃的自制经验核算，只补当前计划的缺口。
- 五种战斗路线：法师、单手战士、双手战士、短弓游侠、长弓游侠，分别选择武器并评估效率、食物与往返补给。
- 农业后台生长，按种子和技能条件补齐田地、升级作物。
- v0.4.3：普通收菜、补种和新一轮采种等待主任务结束或返仓；临近成熟的田块合批处理，计入完整绕路成本，减少频繁中断。确实缺作物材料时仍可提前收取，面板显示延后原因。
- v0.4.4：双手武器换装评估会移除旧盾属性，避免实际降速却误判为升级。
- v0.4.5：新增五种职业路线与市场交易；采矿、钓鱼、伐木优先完成当前背包或批次，制作完成已携材料批次再切换；采集出发前存放占空间的旧物品，避免只采几次就返仓。
- v0.4.6：默认改为阶段成长，优先补齐落后技能，再在同阶段比较收益，避免采矿锻造长期垄断。草药可采购原料，或用 24 金币购买一粒鼠尾草启动种子，自种等待期间继续其他工作。有效装备升级不再要求半小时回本，面板列出当前／下一档装备、穿戴门槛及供料条件；在用装备按实际提升安排安全 +1，强化等级不强制追平。
- 普通盈余优先市场出售；无合适买单则小批挂卖，最多管理 3 笔自有订单。每 30 分钟顺路复核并尝试降价，累计挂售至少 2 小时且重新定价后，才回收确认退回、仍无更好买价的本批余量。查询失败、挂单槽满或冷却只会延后，等待期间继续练级；采购余单及时撤销，不操作原有手动订单。
- 自动出售预算外普通盈余、打造和更换装备，条件合适时进行首级强化。
- v0.4.7：优先预计 10 分钟内、能赶上刷新且经验或金币效率合适的日常／周常任务，长任务顺路积累；完成自动领奖。领取不打断工作，任务切换遵守满包／批次边界。击杀任务经验按领奖时的武器职业发放，法师持法杖领奖获得魔法经验。
- v0.4.8：修复显示炼药却长期为农业升级伐木、采矿的问题：先选择成长目标，落后技能优先于非必需采种及其解锁链；已完成存包但漏过返仓快照时仍能切换。已有种子补田和必要药材供料保留，面板分别显示计划目标与实际工作。
- v0.4.9：生活练级合并当前阶段批次，现货原料先开工；等待种植或条件受限时同轮改选任务，操作确认后不再额外等待固定 4 秒。市场优先出售，至少挂售两小时并重新定价后才允许系统回收，回收资格按具体批次记录，保护新生产库存；收菜等待全部已种田成熟，一趟收完补种，前台药材供料也遵守合批条件。
- 选怪计入整趟补给：食物保留 25% 余量后至少能完成一次击杀，避免低等级法师反复耗粮却打不死怪。
- 连接恢复后继续调度；手动改任务会暂停脚本。

## 安装一次，后续检查更新

先安装 Tampermonkey，再打开上方安装链接并确认安装。原来通过本地文件安装的用户也需从此链接更新一次，以保存固定更新地址。保留一份助手和一个游戏标签页。

在 Tampermonkey 中启用该脚本的更新检查与自动安装更新。作者发布更高版本后，各设备按照自己的设置检查更新；更新完成后刷新游戏，新代码才会运行。各设备首次安装一次即可，游戏角色与脚本运行配置不会通过此仓库同步。

没有安装提示时，在 Tampermonkey 的“从 URL 安装”入口粘贴上方安装链接。

## 使用范围

这是有限时间内的收益规划，不承诺全局最优或真实账号连续运行 24 小时。电脑休眠、关闭页面、服务器维护或登录失效会中断运行。请遵守游戏的自动化规则。

市场报价缺失时保留物品、继续练级并稍后重试；价格及成交量会变化，不能保证挂单成交。交易结果不明时保留记录、同步核实，不重复下单。留货按当前计划及周转储备计算，不保证覆盖未规划的公会、住房或未来切职业需求。公会捐赠、Town 交货及任务点加点尚未自动执行。阶段成长会牺牲部分总经验，供料和后台农业仍可能让个别技能领先，不保证等级完全相同。
