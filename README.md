# Deep Vein Idle 自给成长与职业助手

[安装或更新脚本](https://raw.githubusercontent.com/ljyoukong-cpu/deepvein-idle-helper/main/deepvein-balanced.user.js)

用于 [Deep Vein Idle](https://deepveinidle.com/) 的 Tampermonkey 用户脚本。经验优先，兼顾自给供料、金币、装备和后台农业；默认暂停，首次安装后刷新游戏，选择职业并点击“开始”。

- 自采、自制与按需采购结合；按实时卖盘、筹币时间、往返及放弃的自制经验核算，只补当前计划的缺口。
- 五种战斗路线：法师、单手战士、双手战士、短弓游侠、长弓游侠，分别选择武器并评估效率、食物与往返补给。
- 农业后台生长，按种子和技能条件补齐田地、升级作物。
- v0.4.3：普通收菜、补种和新一轮采种等待主任务结束或返仓；临近成熟的田块合批处理，计入完整绕路成本，减少频繁中断。确实缺作物材料时仍可提前收取，面板显示延后原因。
- v0.4.4：双手武器换装评估会移除旧盾属性，避免实际降速却误判为升级。
- v0.4.5：新增五种职业路线与市场交易；采矿、钓鱼、伐木优先完成当前背包或批次，制作完成已携材料批次再切换；采集出发前存放占空间的旧物品，避免只采几次就返仓。
- 普通盈余比较市场税后收入与系统回收；优先较高买单，也可少量限时挂卖。最多管理 3 笔自有订单，挂卖 10 分钟未成交撤回，采购余单及时撤销，不操作原有手动订单。
- 自动出售预算外普通盈余、打造和更换装备，条件合适时进行首级强化。
- 连接恢复后继续调度；手动改任务会暂停脚本。

## 安装一次，后续检查更新

先安装 Tampermonkey，再打开上方安装链接并确认安装。原来通过本地文件安装的用户也需从此链接更新一次，以保存固定更新地址。保留一份助手和一个游戏标签页。

在 Tampermonkey 中启用该脚本的更新检查与自动安装更新。作者发布更高版本后，各设备按照自己的设置检查更新；更新完成后刷新游戏，新代码才会运行。各设备首次安装一次即可，游戏角色与脚本运行配置不会通过此仓库同步。

没有安装提示时，在 Tampermonkey 的“从 URL 安装”入口粘贴上方安装链接。

## 使用范围

这是有限时间内的收益规划，不承诺全局最优或真实账号连续运行 24 小时。电脑休眠、关闭页面、服务器维护或登录失效会中断运行。请遵守游戏的自动化规则。

市场报价缺失时短暂等待后继续自给或系统回收；价格及成交量会变化，不能保证挂单成交。交易结果不明时保留记录、同步核实，不重复下单。留货按当前计划及周转储备计算，不保证覆盖未规划的公会、住房或未来切职业需求。公会捐赠尚未自动执行。所选职业约束战斗技能；总经验优先仍可能选择生活技能。
